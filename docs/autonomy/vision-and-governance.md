# Vision and governance

## Outcome

Hercules should operate a portfolio of independent projects: ordinary bounded
code changes are planned, verified, independently reviewed, and integrated
with evidence; the operator spends attention only on irreversible production
actions, privilege changes, unusual spend, unclear product decisions, and
meaningful risk exceptions.

This is not unsupervised self-modification. Agent assertions are never proof.
Every conclusion must cite gates, independent review, behavioral evidence, or
an operational receipt.

## Maturity path

1. **Controllable pilot** — today's task/worktree/gate/retry system.
2. **Measured delegation** — typed task classes, reliable evidence, and honest
   failure packets for a small set of repos.
3. **Graph-assisted execution** — proposed and reviewed DAGs, resource-aware
   dispatch, local retry/replanning, and top-level integration verification.
4. **Bounded portfolio autonomy** — several repos progress concurrently under
   budgets and conflict controls; exceptions alone interrupt the operator.

No stage promotes itself merely because child tasks are green. It advances only
after a defined evaluation window proves no degradation in evidence, safety,
or human burden.

## Human boundary

Always require an explicit human decision for production deploy/promote,
destructive action, privilege/security-policy change, external publication,
ambiguous product judgement, and material cost expansion. High-risk findings
may create a well-evidenced improvement task; they never silently rewrite the
rule that protects them.
